側邊欄聊天

Momo AI 的核心功能是以 Chrome Side Panel API 打造的側邊欄聊天介面。

介面概覽

  • 頂部工具列：系統提示詞選擇器、聊天記錄、新對話、設定
  • 訊息區域：Markdown 渲染、思考過程摺疊、操作按鈕
  • 輸入區域：模型選擇、功能按鈕列（🖼️ 圖片上傳、📄 引用頁面、🔍 聯網搜尋）、文字輸入框、字元計數器、送出按鈕

對話操作

  • Enter：送出訊息
  • Cmd+Enter（macOS）：同樣送出訊息
  • Shift+Enter：換行（不送出）
  • Escape：停止生成

自動捲動

對話會自動跟隨最新內容；若你手動向上捲動檢視較早訊息，自動捲動會暫停。回到底部、往下捲至接近底部，或點擊 ⬇ 按鈕，都會恢復跟隨。思考區塊收起或內容重新排版不會被當成手動上捲。

若 AI 回覆包含圖片（含貼圖或 Markdown 圖片），圖片載入完成後高度可能延後變化；處於自動跟隨狀態時會補捲到底部，避免最後文字被輸入區遮住。

串流回覆

回覆以 SSE（Server-Sent Events）串流傳送。依回覆長度採用不同更新頻率：短回覆約每 80ms、中約 300ms、長約 800ms 更新一次，以平衡流暢度與效能。

串流會保留已完成段落，只增量更新最後一段。超長回覆在生成期間先顯示純文字，結束後恢復 Markdown。長對話送出時只附上最近兩輪的歷史圖片，較舊圖片保留在本機記錄。

歡迎畫面與 Prompt Suggestions

尚未開始對話時會顯示播放一次後停留的 Momo 動畫，以及橫向排列、可換行的 Prompt Suggestions（快捷提示），可一鍵開始聊天。詳見 系統提示詞 頁面的 Prompt Suggestions 說明。

頂部工具列的系統提示詞選擇器僅在至少一個提示詞設為可見時顯示；預設 MoMo 為啟用狀態。

編輯訊息

在 user 訊息的操作列點編輯，可修改文字或附加圖片後重新送出。

  • 一般模型（OpenAI、Gemini 等）：編輯會替換該則 user 訊息，並刪除其後的本地對話，再重新生成 assistant 回覆。
  • Hermes / OpenClaw：編輯後會追加一則新 user 訊息（保留原訊息與完整本地歷史），再送給 agent / gateway。這是因為遠端 agent session 已接收的歷史無法由 Momo 回退。
  • 串流生成中無法編輯；請先停止生成。
