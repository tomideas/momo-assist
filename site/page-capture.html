引用頁面內容

將當前瀏覽的網頁內容擷取為 AI 對話的上下文。點擊 📄 後，user 訊息會顯示 Page Referenced / 引用頁面 標籤；頁面內容在送 API 時綁定到該則 user message，不會以中途插入的 system message 形式混在對話歷史中。

使用方式

點擊 📄 按鈕 → 系統擷取頁面 → 顯示預覽卡片 → 輸入問題並送出。可展開預覽檢視或取消引用。

若只引用頁面、輸入框留空就送出，聊天畫面仍只顯示「引用頁面」標籤；Momo 會在送 API 前自動補上預設提問（例如「請根據引用頁面內容回答。」），避免部分本地模型（LM Studio / Qwen 等）因空白 user 訊息報錯。

多輪對話與 token

  • 頁面內容只會注入「最新一則、本身帶有 Page Referenced 的 user message」的 API payload。
  • 後續追問（未再次按 📄）只送可見對話文字，不會重送整份頁面，避免 token 浪費。
  • 若要就同一頁繼續提問且需再次附上全文，請重新點 📄 引用後再送出新訊息。
  • assistant 回覆操作列的 📄 圖示，只會出現在「前一則 user message 本身有 Page Referenced」的回覆上，並只開啟該輪綁定的頁面內容。
💡 聯網搜尋是否觸發，依你輸入框中的原始文字判斷，不會把整份引用頁面內容誤當成搜尋 query。

擷取模式

於設定 → 引用頁面可選擇擷取模式。新安裝或未設定時，預設為 Smart Capture（推薦）。

Smart Capture（推薦）

依頁型智能提取文章結構或可見文字，不套用字元上限。若精簡內容覆蓋率不足，會回退到較完整的可見正文。擷取在頁面副本處理，不會改動原網站排版。

Limited Capture（限制字數）

在智能擷取後套用字元上限；新安裝或尚未設定時預設為 50,000，可設定 1,000–200,000 字元。既有使用者已儲存的數值保持不變。

Full Page（整個頁面）

擷取並傳送頁面中已載入的全部內容，不套用字元上限；適合智能模式漏掉重要內容時使用。

內容完整性

未載入的虛擬內容、收合區域、iframe、canvas、Shadow DOM 或字數截斷可能造成缺漏。引用卡片會標示可能不完整，並提醒 AI 不能將擷取內容視為完整資料。需要時先在原頁面展開或載入內容，再重新引用。

⚠️ 上下文用量Smart Capture 與 Full Page 不設字元上限，內容越長，模型上下文與 API 用量越高；需要控制用量時選擇 Limited Capture。

追蹤擷取狀態

系統會記錄 URL，避免在同一頁面重複擷取時產生多餘負擔。
