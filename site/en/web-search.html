Web Search

Built-in web search lets AI query the latest information from the internet during conversations.

Enabling Search

Click the 🔍 search icon to toggle; when enabled, the extension searches only when the message looks like it needs the web (news, prices, weather, explicit "search the web", URLs in the text, and similar signals)—not on every message.

💡 Auto-Trigger Even when search is turned off, messages starting with "look up", "search", or "search for" will automatically trigger a web search.

OpenRouter Server-Side Search

OpenRouter uses extension-side search results first. When search is needed but client-side search fails or returns no usable results, it falls back to :online server-side search.

Search Modes

  • Quick Search on: Uses search summaries only for faster results.
  • Quick Search off (default): Also reads page bodies from the first three results for more complete evidence.

Successfully reading a URL in your message does not automatically trigger another search. Additional searches are used for explicit requests for recent information, comparisons, or further research. Sources are deduplicated and ranked by relevance.

Search Settings

In settings you can adjust: search engine, number of results (1–20), quick search mode, auto-visit URLs, default search on, and test search.

Viewing Search Sources

Click the 🔍 button to view source titles, URLs, and summaries.
