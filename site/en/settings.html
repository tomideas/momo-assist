Settings Overview

Opening Settings

You can access settings from the ⚙️ icon at the top of the sidebar, or by right-clicking the extension icon → Options to open the full settings page.

Settings Categories

General

Interface language, theme, font size (12–20), font weight (200–700), and Auto-generate chat titles (enabled by default). For language and interface details, see Multi-language and Chat History.

AI Reply Language

Independent of interface language, with message, interface, and fixed-language options. See language policies. The conversation font slider displays its current value; input text stays at 14px.

Sidebar

Whether to show the Float Ball, sidebar-related options, and Shortcuts hints.

AI Models

Provider, API endpoint, API key, model list, and connection testing. See AI Providers for details.

Web Search

Search engine, number of results, and advanced options. See Web Search for details.

Page Capture

Modes include Smart Capture (default), Limited Capture, and Full Page. Only Limited applies a character cap (default: 50,000). See Page Capture for details.

Text-to-Speech

TTS voice, rate, pitch, and Auto-read AI replies (off by default). See Text-to-Speech (TTS) for details.

Prompts

Customize and manage system prompts and Prompt Suggestions. See System Prompts for details.

Config Backup

The left nav and bottom of Settings include a Config section for JSON export and import — useful for backups or migration.

  • Exports include: providers, models, prompts, prompt suggestions, TTS, page capture, web search, appearance, and behavior settings
  • Does not include: chat history or image attachments
  • Exported files may contain API keys — do not share them publicly

Version Information

The bottom of Settings displays the installed extension version. Compare it with the changelog.
